# Lenovo Xiaoxin Pad Pro 2021 (TB-J716F / SM8250-AC) Ubuntu 24.04 硬件与桌面修复汇总

本文档汇总了在 Linux `7.4.0-rc2-j716f` 内核及 Ubuntu 24.04 ARM64 (GNOME 46 Wayland) 桌面上已验证通过的全部修复内容（基于最新 `main` 分支，已包含 PR #1 USB OTG 与 PR #2 ADSP 堆内存修复）。

## 一、内核与设备树 (Kernel & DTS)

1. **22.5W USB-PD + QC2.0/3.0 (APSD/HVDCP) 快充**
   - `sm8250-lenovo-j716f.dts`：移除 `&pm8150b_typec` 上的 `pd-disable`，配置 `op-sink-microwatt = <22500000>`、5V/3A、9V/2.5A、12V/2A `sink-pdos` 及 5V/1.5A `source-pdos`。
   - `qcom_pmic_typec_port.c`：实现 `qcom_pmic_typec_port_set_current_limit()`，开启 PM8150B SMB5 HVDCP 自动检测/认证（`0x1362 = 0x7c`, `0x1360 = 0x07`），并通过 1500ms 延迟工作队列检测传统 56k Rp USB-A 线缆的 APSD 结果（`0x1306`/`0x1307`），对 DCP/HVDCP 提速至 `ICL=2500mA / FCC=4200mA`，同时保持电脑 USB SDP 500mA 安全限制。
2. **Goodix GT738x 息屏唤醒恢复 + 联想主动电容笔 (WGP) 支持**
   - `goodix.c` / `goodix.h`：修复休眠恢复时 `goodix_send_cfg()` 返回 `-EINVAL` 导致触控异常的问题；逆向解析 GT738x 主动笔数据包（`GOODIX_GT738X_PEN_FLAG = BIT(5)`），完整支持 4096 级压感（`ABS_PRESSURE`）、±90° 倾斜角（`ABS_TILT_X`/`ABS_TILT_Y`）、悬浮光标（`BTN_TOOL_PEN`）、笔身双按键（`BTN_STYLUS`/`BTN_STYLUS2`）与硬件防误触，开机即注册 `/dev/input/eventX: Goodix Active Pen`。
   - `sm8250-lenovo-j716f.dts`：移除不存在的 `goodix,config-name = "j716f_cfg.bin"`，直接使用芯片内置 Flash 配置。
3. **CPU7 3.19 GHz 满血频率与硬件告警清零**
   - `sm8250-lenovo-j716f.dts`：为 Snapdragon 870 (`SM8250-AC`) 补充 `cpu7_opp22: opp-3187200000`；禁用重复节点 `&pm8009_pon` 消除 `EEXIST`；启用 `&pm8150l_flash` 后置双 LED 闪光灯（`led-0`/`led-1`，手电筒 300mA / 闪光 1000mA / 1280ms）。
   - `es7210.c`：设置 `.idle_bias_on = 1`，消除 `sound/soc/soc-component.c` 启动 WARN。
4. **内核配置建议 (`.config`)**
   - 启用 `CONFIG_LEDS_CLASS_FLASH=y`、`CONFIG_LEDS_QCOM_FLASH=y`（闪光灯/手电筒）。
   - 启用 `CONFIG_SQUASHFS_LZO=y`、`CONFIG_SQUASHFS_LZ4=y`、`CONFIG_SQUASHFS_ZSTD=y`（确保 Snap 软件商店与桌面应用如 Krita/Snap Store 正常挂载）。
   - initramfs 追加 `/lib/firmware/regulatory.db*` 以支持完整 Wi-Fi 6 5GHz/160MHz 国家码信道。

## 二、用户态工具与桌面修复

1. **微信/语音通话全双工无声彻底修复 (`tools/audio/`)**
   - WirePlumber 配置（`51-j716f-audio.conf` / `51-j716f-audio.lua`）：启用 ALSA timer scheduling（`api.alsa.disable-tsched = false`），调整 `period-size = 1024`、`period-num = 4`、`headroom = 1024`、`start-delay = 1024`，解决全双工通话时 `q6asm-dai` `pcm0p` 偶发卡死无声问题。
   - `j716f-audio-watchdog` + `j716f-audio-watchdog.service`：后台监控 `pcm0p` 冻结状态并自动无感恢复。
2. **Wi-Fi 6 满血性能调优 (`configs/ubuntu/j716f-desktop/`)**
   - `nm-90-j716f-wifi-perf.conf`（部署至 `/etc/NetworkManager/conf.d/90-j716f-wifi-perf.conf`）：关闭 Wi-Fi 省电（`wifi.powersave = 2`），解决 500M+ 宽带吞吐受限与延迟抖动。
   - `sysctl-90-j716f-wifi-perf.conf`（部署至 `/etc/sysctl.d/90-j716f-wifi-perf.conf`）：增大 TCP 收发缓冲区至 16MB。
3. **Adreno 650 真实 GPU 硬件占用监控器 (`tools/gpu-monitor/`)**
   - `j716f-gpu-monitor` + `.desktop`：针对 GNOME 任务中心/Mission Center 无法识别高通 `msm` DRM GPU 占用的问题，直接读取内核 `drm-engine-gpu` fdinfo 硬件忙时计数器、devfreq 频率（305–670 MHz）、GPU 温度、CPU7 3.19GHz 频率与电池实时功耗，实时反映真实 GPU 负载。
4. **无边框应用全局触控拖拽 GNOME 46 扩展 (`tools/gnome-extensions/j716f-touch-drag@local/`)**
   - 支持在微信、QQ、中国移动云盘等无原生标题栏的 Electron / XWayland 应用顶部区域单指直接拖拽移动窗口。
5. **手电筒应用 (`tools/flashlight/`)**
   - `j716f-flashlight` + udev 规则 + `.desktop`：通过 `pm8150l_flash` sysfs 提供图形化亮度调节与一键开关。
6. **前置摄像头本地人脸识别登录与 `sudo` 解锁 (`tools/face-unlock/`)**
   - 基于前置 `s5k4h7` 摄像头 + OpenCV YuNet/SFace 本地离线模型，提供 `j716f-face-cli`、`j716f-face-gui` 与安全的 `pam_exec.so` 脚本 `j716f-face-pam`。
7. **中文语言包防清理 & 桌面体验配置 (`configs/ubuntu/j716f-desktop/`)**
   - `zz-j716f-keep-zh-cn`（部署至 `/etc/dpkg/dpkg.cfg.d/zz-j716f-keep-zh-cn`）：覆盖系统默认 `excludes` 规则，保留 `zh_CN` `.mo` 翻译文件（解决 Krita 等软件安装后缺少中文界面）。
   - `j716f-wechat-cam`（摄像头防偏红/视野修正）、`90-j716f-wayland-apps.conf`、`90-j716f-osk`、`35-j716f-window-drag`。
8. **QCA6390 蓝牙休眠唤醒掉线彻底修复 (`tools/bluetooth/`)**
   - 根因：系统休眠唤醒后高通串口控制器 `998000.serial` (`qcom_geni_serial`) 陷入异常 `runtime_status = suspended`，导致 `hci0: command 0x0c01/0xfc00 tx timeout (-110)` 永久卡死。
   - `99-j716f-bt-uart-pm.rules`：保持 `998000.serial` 电源管理为 `on`，防止串口异常自动挂起。
   - `j716f-bt-recover` + `99-j716f-bt-resume`（部署至 `/lib/systemd/system-sleep/`）：休眠唤醒后自动检测 `hci0` 状态，掉线时自动解绑/重绑 `998000.serial` 并在 3 秒内恢复蓝牙。
   - `j716f-bt-watchdog` + `j716f-bt-watchdog.service`：后台监控 `hci0` 硬件超时或地址清零并自动无感自愈（同时尊重用户手动关闭蓝牙）。
9. **磁吸保护套合盖关屏 / 开盖唤醒修复（ROHM BU52053NVX 霍尔传感器，`tools/hall-lid/` + DTS）**
   - 硬件定位：从原厂 SLPI 传感器注册表（`kona_bu52053nvx_0.json`）确认磁吸霍尔传感器直连 SM8250 TLMM `gpio121`（低电平有效）。
   - 内核设备树：`sm8250-lenovo-j716f.dts` 的 `gpio-keys` 中补充 `hall-sensor` 节点（`gpios = <&tlmm 121 GPIO_ACTIVE_LOW>`、`EV_SW` / `SW_LID`、`debounce-interval = <60>`、`wakeup-source`），支持重编内核后的深度休眠开盖硬件唤醒。
   - 免重编内核即刻生效方案（`tools/hall-lid/`）：`j716f-hall-lid` 通过 Linux GPIO v2 双沿硬件中断（0% 待机 CPU）监听 TLMM `gpio121`，经 `/dev/uinput` 注册标准 `SW_LID` 与 `KEY_WAKEUP` 事件，配合 `j716f-hall-lid.service` 与 `90-j716f-hall-lid.conf` 实现合盖自动锁屏熄屏、开盖瞬间唤醒亮屏（已真机验证通过）。
