# Lenovo Xiaoxin Pad Pro 2021 (TB-J716F) 硬件驱动与桌面体验综合修复记录

本记录汇总在 **Ubuntu 24.04.5 LTS ARM64 (GNOME 46 Wayland)** + **Linux 7.4.0-rc2** 实机上对比原厂 Android ZUI 镜像（`dtbo_3.dts` / `boot.img` / `vendor_a`）完成并验证的全部修复项（与已提交的 PR #1 USB OTG、PR #2 ADSP Heap 死锁修复互补）。

## 一、内核与设备树修复

1. **22.5W USB-PD 快充支持**
   - `sm8250-lenovo-j716f.dts`：移除 `&pm8150b_typec` 的 `pd-disable;`，补齐 `op-sink-microwatt = <22500000>` 及 5V/3A、9V/2.5A、12V/2A `sink-pdos`。
   - `drivers/usb/typec/tcpm/qcom/qcom_pmic_typec_port.c`：实现 `qcom_pmic_typec_port_set_current_limit()`，写入 PM8150B SMB5 充电寄存器（`0x1360`、`0x1366`、`0x1341`、`0x1370`、`0x1061`，50 mA/LSB，上限 4200 mA）。
2. **Goodix GT738x 休眠唤醒触屏失灵修复**
   - `drivers/input/touchscreen/goodix.c`：`goodix_resume()` 中当 `goodix_send_cfg()` 返回 `-EINVAL` 时改为告警并保留芯片内置 Flash 配置，继续执行 `goodix_request_irq()`，彻底修复息屏唤醒后触摸无响应问题。
   - `sm8250-lenovo-j716f.dts`：移除缺失的 `goodix,config-name = "j716f_cfg.bin";`。
3. **SM8250-AC 超大核 CPU7 3.19GHz 睿频修复**
   - `sm8250-lenovo-j716f.dts`：在 `&cpu7_opp_table` 中补齐 `cpu7_opp22: opp-3187200000`，消除 `Voltage update failed freq=3187200`，实机解锁 `3187200 kHz`。
4. **消除 `qcom-pon` 重复注册报错（`-17 / EEXIST`）**
   - `sm8250-lenovo-j716f.dts`：禁用重复的 `&pm8009_pon` 节点。
5. **后置相机闪光灯 / 补光灯启用（`pm8150l_flash`）**
   - `sm8250-lenovo-j716f.dts`：启用 `&pm8150l_flash`（`led-0` / `led-1`，常亮 300 mA / 闪光 1000 mA / 1280 ms），内核配置开启 `CONFIG_LEDS_CLASS_FLASH=y` 与 `CONFIG_LEDS_QCOM_FLASH=y`，注册 `/sys/class/leds/white:flash-0` 与 `white:flash-1`。
6. **消除音频 `es7210` `snd_soc_component_probe` 内核 WARNING**
   - `sound/soc/codecs/es7210.c`：在 `es7210_component_driver` 中补齐 `.idle_bias_on = 1`，消除 `WARNING: sound/soc/soc-component.c:1472`。
7. **Wi-Fi 监管域数据库（`regulatory.db`）**
   - 安装 `wireless-regdb` 并将 `/lib/firmware/regulatory.db*` 追加至 initramfs，消除启动早期 `cfg80211: failed to load regulatory.db`。

## 二、用户态工具与桌面体验修复

1. **后置手电筒控制程序（`tools/flashlight/`）**
   - 原生 GTK4 触控界面 `j716f-flashlight` + udev 免密规则 `99-j716f-flash-led.rules`，支持常亮亮度调节、双通道切换与单次闪光测试。
2. **前置摄像头本地人脸识别与刷脸解锁（`tools/face-unlock/`）**
   - 基于 OpenCV 4.6 + YuNet (`face_detection_yunet_2022mar.onnx`) + SFace (`face_recognition_sface_2021dec.onnx`)，直接通过 `/opt/j716f-camera/bin/cam` 采集前置 `s5k4h7`，支持 0°/90°/270°/180° 横竖屏自适应检测、GTK4 图形化录入/测试，以及安全的 `pam_exec.so` 接入（支持锁屏/登录/`sudo` 刷脸，SSH 或无样本/失败时自动回退密码）。
3. **前后置摄像头偏红与虚拟摄像头视场角修复（`tools/camera/`）**
   - 修正 `/opt/j716f-camera/lib/spa-0.2/libcamera/libspa-libcamera.so` 中 DRM→SPA RGB/RGBA 字节序映射表（解决前后置画面泛红问题）。
   - 更新 `j716f-wechat-cam` 为全视场角 `3200x1800 RGBA` 缩放输出 `640x480 YUY2`。
4. **Wayland 窗口拖动与锁屏虚拟键盘修复（`configs/ubuntu/j716f-desktop/`）**
   - 配置 Qt5/Qt6/Electron 原生 Wayland 与 `qgnomeplatform-qt5` 标题栏触控拖动（`90-j716f-wayland-apps.conf`、`35-j716f-window-drag`）。
   - 修复 GDM 锁屏/登录界面屏幕键盘弹出配置（`90-j716f-osk`）。
